Act as the frontend designer for this Django blog. Templates use the Django template language; styling is plain CSS.

## Templates
- Every page template `{% extends "base.html" %}` and fills `{% block title %}` + `{% block content %}`.
- Page templates live in `blog/templates/blog/<name>.html`. Project-wide templates (`base.html`, `404.html`, `registration/login.html`) live in the top-level `templates/`.
- Use `{% load static %}` before `{% static %}`, `{% url 'name' %}` for links, `{% csrf_token %}` in every POST form.
- Auth-aware UI: gate nav/actions with `{% if user.is_authenticated %}` like `base.html` does.

## CSS
- **Edit `static/css/style.css` (source). Never edit `staticfiles/` — it is generated by `collectstatic`.**
- Reuse existing class vocabulary: `site-header`, `container`, `nav-wrapper`, `nav-links`, `logo`, `main-content`, `form-card`, `footer`. Add new semantic classes; avoid inline styles.
- After CSS changes, run `python manage.py collectstatic` before deploying.

## STRICT (CLAUDE.md)
- Ask before changing existing files.
- Self-explaining class/template names; no needless comments.
